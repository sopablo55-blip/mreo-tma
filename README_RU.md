# МРЭО — общий рынок и онлайн-рейтинг через Supabase

В комплекте:
- `index.html` — игра с общим рынком и серверным рейтингом;
- `telegram-sync-patch.js` — клиентский вызов Edge Function;
- `cars.js` — каталог машин, необходимый `index.html`;
- `supabase/functions/mreo-api/index.ts` — серверная логика и проверка подписи Telegram `initData`;
- `supabase/config.toml` — отключает стандартную JWT-проверку платформы для этой функции, потому что вход проверяется по Telegram `initData`;
- `init.sql` — поля, индексы и атомарные SQL-операции рынка.

## Что изменено

- Полностью удалена генерация локальных объявлений `makeLot()` и список фальшивых игроков.
- Рынок загружается только из `market_lots`; свои объявления и объявления других игроков отображаются раздельно.
- Выставление номера (`list`), покупка (`buy`) и снятие (`cancel`) выполняются через `mreo-api`.
- Покупка, перевод игровых рублей продавцу и передача номера выполняются одной транзакцией в SQL RPC — два игрока не смогут одновременно купить один лот.
- При продаже номер возвращается в гараж; при покупке списывается баланс покупателя, начисляется продавцу, номер меняет владельца.
- Рейтинг загружается из `profiles` и `plates` и сортируется по балансу плюс стоимости номеров.
- Баланс сохраняется как разница от последнего серверного значения, чтобы начисление продавцу не затиралось устаревшим состоянием уже открытой игры.
- Гостевой запуск остаётся локальным; общий рынок и рейтинг доступны из Telegram Mini App.

## 1. Обнови файлы сайта

Скопируй `index.html`, `telegram-sync-patch.js` и `cars.js` в одну папку на HTTPS-хостинге. Не переименовывай `telegram-sync-patch.js` и `cars.js`: HTML подключает их по этим именам.

## 2. Выполни SQL

Открой Supabase Dashboard → SQL Editor и выполни весь файл `init.sql`.
Он не удаляет таблицы и данные. Он создаёт необходимые функции `mreo_save_profile`, `mreo_market_list`, `mreo_market_cancel`, `mreo_market_buy` и ограничивает их выполнение ролью `service_role`.

## 3. Секреты и деплой Edge Function

Из корня проекта (там, где находится каталог `supabase/`) выполни команды CLI:

```bash
supabase login
supabase link --project-ref cqwtbowilgtwwhicsxyp
supabase secrets set TELEGRAM_BOT_TOKEN="ТОКЕН_ТВОЕГО_TELEGRAM_БОТА"
supabase secrets set SUPABASE_SERVICE_ROLE_KEY="ТВОЙ_НОВЫЙ_SERVICE_ROLE_SECRET"
supabase functions deploy mreo-api
```

`supabase/config.toml` задаёт `verify_jwt = false`. Это необходимо: Supabase не должен требовать JWT Supabase от Telegram Mini App; функцию защищает собственная криптографическая проверка `initData` на сервере.

**Не вставляй `service_role` или токен Telegram-бота в HTML/JS и не отправляй их в чат.** Ранее раскрытый secret key следует отозвать и заменить новым.

## 4. Настрой Telegram Mini App

В BotFather укажи HTTPS URL опубликованного `index.html` как адрес Mini App. Открывай игру кнопкой Mini App бота. При обычном открытии HTML вне Telegram общий рынок и рейтинг не будут доступны.

## 5. Быстрая проверка

1. Открой игру через Telegram на двух разных аккаунтах.
2. На первом аккаунте получи номер и выставь его на рынок.
3. На втором аккаунте открой вкладку «Рынок»: объявление первого игрока должно появиться.
4. Купи номер на втором аккаунте: баланс покупателя уменьшится, баланс продавца увеличится, номер появится в гараже покупателя.
5. Выставь другой номер и нажми «Снять»: объявление исчезнет, номер вернётся в гараж.
6. Открой «Топ»: список должен содержать профили из базы, а не заранее прописанные имена.

## Примечание по экономике

Сервер защищает сделки и проверяет принадлежность номера/объявления. Остальная игровая прогрессия (получение номеров, колесо, награды и тюнинг) в этой версии по-прежнему рассчитывается клиентом и синхронизируется с профилем. Поэтому это ещё не полноценная защита всей игровой экономики от модификации клиента.
